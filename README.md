# Homelab Platform

Reproduzierbare Homelab- und DevOps-Umgebung zum Lernen, Betreiben und Dokumentieren moderner Infrastruktur.

## Ziele

- Docker-basierte Services reproduzierbar betreiben
- Git und CI/CD praktisch einsetzen
- Infrastruktur schrittweise automatisieren
- Kubernetes und Infrastructure as Code anhand realer Workloads lernen
- Konfigurationen so aufbereiten, dass sie nachvollziehbar und wiederverwendbar sind
